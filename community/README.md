# 오늘의 직장인 — 재구성 프로토타입

진단서(kutter72.co.kr 직장인 커뮤니티)에서 제안한 구조를 실제로 동작하게 만든 것입니다.
도메인 연결은 아직 하지 않았고, 로컬에서 열어 보는 단계입니다.

## 실행

```bash
node community/server.js
```

http://127.0.0.1:4173 으로 접속합니다. 포트를 바꾸려면 `PORT=5000 node community/server.js`.

외부 패키지가 없습니다. Node 18 이상이면 그대로 돕니다.

## 검증

```bash
node --test community/test/api.test.js
```

```bash
node community/test/crosscheck.js
```

`crosscheck.js`는 자체 인스턴스를 임시 저장소에 띄워 검증하므로,
실행해도 실제 사이트의 데이터는 바뀌지 않습니다.

## 데이터에 대하여

**미리 채워 넣은 숫자가 없습니다.** 글·표·조회수·반응·게임 점수·자격증 점수·독서 진도는
전부 실제 기록에서 계산합니다. 처음 열면 모든 수치가 0입니다.

`catalog.js`에 있는 것은 **운영자가 정한 콘텐츠**입니다 — 지역·메뉴 목록, 전기 문제 3개,
독서 목록 4권. 이 콘텐츠는 기존 kutter72.co.kr의 '퇴근 후 성장' 화면에서 그대로 가져왔습니다.
문제의 정답과 해설은 서버에만 두고, 채점도 서버에서 합니다.

계정도 없습니다. 인증 배지(L2)를 보시려면 **회사 이메일 도메인**으로 가입하세요
(gmail·naver·daum 등 개인 메일 도메인은 인증 대상에서 제외됩니다).
`@내회사.co.kr` 처럼 개인 메일이 아닌 주소면 가입 후 '내 서랍'에서 인증할 수 있습니다.

처음부터 다시 시작하려면 `community/data/db.json` 을 지우고 서버를 다시 띄우면 됩니다.

## 구조

```
community/
  server.js          HTTP 서버 · 라우팅 · 정적 파일 · 공유 카드(OG) 주입
  lib/
    store.js         JSON 파일 영속 저장 (임시 파일 + rename 으로 원자적 쓰기)
    identity.js      신원 4단계 · 공개 범위 4단계 · 열람 권한 판정
    api.js           API 핸들러 · 점심 집계 · 자동 필터
    catalog.js       운영자 설정 (지역 · 메뉴 · 챌린지 정의). 사용자 데이터는 없음
  public/
    index.html       셸 (경로별 title/OG 를 서버가 주입)
    styles.css       디자인 토큰 (라이트/다크) · 컴포넌트
    app.js           클라이언트 라우터 · 화면 · SVG 아이콘
  test/
    api.test.js      자동화 테스트
    crosscheck.js    저장 파일 직접 대조
  data/db.json       실행 중 생성됨. 지우면 초기 데이터로 다시 만들어집니다.
```

## 진단서 지적 사항 대응

| 항목 | 이전 | 지금 |
|---|---|---|
| F-01 글 저장 | `localStorage` (작성자만 봄) | 서버 파일 저장 (모두가 봄) |
| F-02 점심 데이터 | 코드에 박힌 고정값 | 저장된 표를 매번 다시 집계 |
| F-03 계정 | 없음 | L0 손님 / L1 아이디 / L2 인증 / 가면 |
| F-03 공개 범위 | 공개·비밀 2단계 | 전체·회원·인증·비공개 4단계 |
| F-04 주소 | 전 화면이 `/` 하나, iframe | `/lunch` `/talk/:id` 등 실제 경로 + 공유 카드 |
| F-06 디자인 | 폰트 3종 · 배경 3종 | 토큰 1벌 + 다크 모드 |
| F-07 접근성 | 대비 미달 53건, 8px 글자, 하단 탭 6개 | 대비 미달 0건, 최소 13px, 탭 5개 |
| F-08 문구 | 개발 메모 노출 | 사용자 언어로 교체 |
| 09 운영 | 신고 수단 없음 | 신고 + 누적 3건 자동 가림 + 자동 필터 |
| 독서 진도 | '보스의 탄생'이 `0 / 쪽 · NaN%` | 총 쪽수를 입력받아 계산, 모르면 퍼센트를 만들지 않음 |
| 자격증 문제 | 정답이 브라우저에 노출 | 정답·해설은 서버에만, 채점도 서버에서 |

## 아직 안 한 것

- 알림 (내 글에 댓글 달렸을 때)
- 점심시간 실시간 대화방
- Pretendard 셀프 호스팅 (현재는 설치돼 있으면 쓰고, 없으면 시스템 글꼴로 대체)
- 이용약관 · 개인정보처리방침 실제 문서
- 운영자 콘솔 (신고 목록 조회·처리 화면)
- 데이터베이스 (지금은 JSON 파일 — 동시 사용자가 늘면 교체 필요)
