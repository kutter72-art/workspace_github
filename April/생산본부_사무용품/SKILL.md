## 데이터 처리 규칙

### 비고(K열) 판별 기준

| 조건 | 비고 값 |
|------|---------|
| 이전달 없음, 당월 있음 | **신규** |
| 이전달 있음, 당월 없음 | **미구매** |
| 당월 수량 > 이전달 수량 | **증가** |
| 당월 수량 < 이전달 수량 | **감소** |
| 수량 동일 | **동일** |

### 수식 (Excel 수식으로 작성 — 절대 하드코딩 금지)

```
E{r} = =C{r}*D{r}           ← 이전달 금액
H{r} = =F{r}*G{r}           ← 당월 금액

동일/증가/감소 → I{r}=F{r}-C{r},  J{r}=H{r}-E{r}
신규           → I{r}=F{r},        J{r}=H{r}
미구매         → I{r}=C{r},        J{r}=E{r}

합계행:
C합 = =SUM(C4:C{N})
E합 = =SUM(E4:E{N})
F합 = =SUM(F4:F{N})
H합 = =SUM(H4:H{N})
I합 = =F합-C합
J합 = =H합-E합
```

### 숫자 형식

| 열 | 포맷 |
|----|------|
| 수량(C,F) | `#,##0` |
| 단가(D,G) | `#,##0` |
| 금액(E,H) | `#,##0` |
| 증감(I,J) | `\+#,##0;\-#,##0;"-"` |

> 원본 파일: 동일 폴더의 `template_증감분석.xlsx`

### 폰트
- 전체: **맑은 고딕**, size=10 (타이틀만 12)

### 행 높이

| 행 | 높이 |
|----|------|

| 2 (그룹헤더) | 25.8 |
| 3 (세부헤더) | 22.05 |
| 4~N (데이터) | 18.0 |

### 병합셀
- A1:K1, A2:B2, C2:E2, F2:H2, I2:K2
- 범례행: A{N+3}:K{N+3}, A{N+4}:K{N+4}

### 테두리
- left=medium, right=thin, bottom=hair

### 인쇄 설정
- orientation=landscape (가로 방향)

## 실행 흐름

1. 소스 폴더에서 구매 목록 이미지 또는 Excel 읽기
2. 사용자 입력에서 두 달 데이터 파싱
3. 비고 판별 (신규/미구매/동일/증가/감소)
4. Workbook 생성 → 스타일/레이아웃 적용
5. 데이터 행 + 수식 입력
6. 합계 행 + 범례·주석 삽입
7. Claude 컴퓨터에서 xlsx 생성 후 **Filesystem:write_file로 로컬 PC 저장**
8. 수식 오류 검증 후 완료 보고

## 주의사항

1. **수식은 반드시 Excel 수식으로** — Python 계산값 하드코딩 금지
2. **미구매 행 I·J열** — 양수 표시 (이전달에만 있던 항목)
3. **동일 항목 I·J열** — 수식 포함, 결과 0은 포맷에 의해 "-" 표시
4. **저장 위치** — 반드시 로컬 PC 소스 폴더와 동일 경로에 저장
5. **다음 달 작업 시** — 해당 월의 하위 폴더(예: May)를 새로 만들고 동일 구조 적용
